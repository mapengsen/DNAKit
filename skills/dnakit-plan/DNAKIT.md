# DNAKit 接入说明

正式技能名称：`dnakit-plan`。在 Codex 中安装：

```bash
dnakit skills install dnakit-plan --agent codex
```

本 Skill 指导任务规划，不执行科研流程。连接 DNAKit MCP 后，Codex 可以通过只读的工具和技能检索入口调查可用能力。计划应记录实际选用工具的依赖。使用本 Skill 无需单独配置 DeepSeek 模型或密钥；对话模型由 Codex 会话提供。

本 Skill 不附带脚本。审阅和确认流程见 [SKILL.md](SKILL.md)。安装 Skill 不会自动配置 DNAKit MCP，也不会安装后续分析所需的软件或数据。

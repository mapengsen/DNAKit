# DNAKit Skills

DNA／基因组学技能集合：统一搜索、按需安装、保留原作者及许可证。

当前快照：2026-09-12。共 **536** 个技能：526 个 DNA 相关工作流、9 个组合流程必需的辅助技能、1 个 DNAKit 入口。

每个子目录包含一个 `SKILL.md` 及所需辅助文件；原始来源和修改记录保留在 `UPSTREAM.md`。运行依赖以各技能说明为准。

```bash
# 在 DNAKit 源码根目录安装当前版本
python -m pip install -e "."
dnakit skills search "变异注释" --limit 5
dnakit skills install dnakit --agent codex
dnakit skills install variant-annotation --agent codex
dnakit skills cite variant-annotation
```

安装入口后，在 Codex 中使用 `$dnakit` 描述任务。也支持 `--agent claude-code`、`--agent cursor`；默认安装到当前项目，可添加 `--global`。

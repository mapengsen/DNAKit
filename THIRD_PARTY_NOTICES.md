Copyright, attribution, source URLs and pinned revisions are retained in each skill's
`UPSTREAM.md`, accompanying notices, and `registry/catalog.json`. Individual author
notices inside skill directories remain intact. Modified files are listed in the
catalog and their provenance files, and carry a modification notice where required.

SciAgent's README expressly identifies the frontmatter license as the underlying
tool's license; its original workflow text uses CC-BY-4.0. This differs from K-Dense
and ClawBio, where individual skill license overrides must be respected.

DeepMind science-skills explicitly separates Apache-2.0 software from CC-BY-4.0
other materials. Both complete license texts, Google's copyright statement, the
README scope declaration, and SKILL_LICENSES.md accompany each installed skill.
MYRIAD likewise separates procedural implementations from explanatory materials;
its LICENSE.md, Apache and CC BY texts, NOTICE.md, and citation are retained.

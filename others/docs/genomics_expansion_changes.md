# DNA 方向扩展变更清单

版本说明：在当前源码中加入分层 DNA 能力扩展，新增 9 个科学函数、9 个集成函数、19 项外部分析和 7 类 MCP 连接；Skills 从 536 增至 560，补齐 37 个方向的 166 条来源记录与 88 条检索式。没有发布到 PyPI。

## 验证

- 255 项基因组／Agent／Skills 回归、22 项真实本地 MCP 协议测试、6 项目录重建回归通过。
- 新运行时代码通过 Ruff 与严格类型检查；中英文 MkDocs 严格构建、8 个原生文档示例通过。
- Pyrodigal、Chamaeleo、scadnano 使用真实依赖验证；PLINK 四项使用确定性人工数据验证，不代表真实生物学预测精度。
- 560 个 Skill、4615 个资源文件及旧 536 条记录保留已验证。最终 wheel 与当前运行时代码／JSON／catalog 逐字节一致，4615 个打包资源通过 SHA-256 校验。
- 外部软件与模型服务仍需按需安装和配置；其余 15 项 CLI 后端未做真实软件执行，7 类 MCP 上游账号／模型未连接。

详细记录见 [验证清单](../../registry/genomics-expansion-validation.json)、[真实 PLINK 记录](../../registry/genomics-backend-validation.json)、[Skills 导入审查](../../registry/genomics-skills-review.json)。

## 执行示例

在仓库根目录安装本地源码以及育种、基因识别、MCP 可选依赖：

```bash
pip install -e ".[bio-analysis,genomics-genes,agent]"
```

检索 DNA 存储工作流：

```bash
dnakit skills search "DNA存储"
```

查询所有已登记的外部分析：

```bash
python -c "from dnakit.integrations import list_analyses; print([x['id'] for x in list_analyses()])"
```

复核来源索引与 FAQ 一致性：

```bash
python others/skills/build_genomics_survey.py --check
```

校验 Skills 来源和资源：

```bash
python others/skills/sync_genomics_expansion.py --check
```

使用已安装的 PLINK 2 验证四项外部分析，并输出到新目录：

```bash
python others/validation/genomics_backends.py --plink2 /path/to/plink2 --output ./validation-results
```

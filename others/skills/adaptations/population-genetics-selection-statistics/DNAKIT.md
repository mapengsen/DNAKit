# DNAKit integration

Canonical skill: `population-genetics-selection-statistics`.

```bash
python -m pip install dnakit
dnakit skills doctor population-genetics-selection-statistics
dnakit skills install population-genetics-selection-statistics --agent codex
```

Follow SKILL.md for the scientific procedure and interpretation. DNAKit supplies the skill and its listed local resources. Real scientific libraries, command-line programs, models, reference databases and service credentials retain their own requirements.


## Bundled scripts

Find scripts and run the relevant one with its documented arguments:

```bash
dnakit skills scripts population-genetics-selection-statistics
dnakit skills run population-genetics-selection-statistics --script examples/selection_scan.py -- <documented arguments>
```

The command resolves files from the installed DNAKit package; a checkout of the upstream skill collection is unnecessary. It forwards standard input/output and exit status. Python callers can use `dnakit.workflows.run(skill_id, script, arguments=[...], workdir=...)` for bounded captured output.

## 审查中已修正

- 为不同分支长度的 tuple 和可空浓度结果补充显式类型，避免静态类型误判。
- NUPACK 目标缺陷计算现在校验目标结构与概率矩阵对应的实际链序列，而不只比较长度。
- 无配对的单链与多链结果分别标记为 `unstructured` 和 `unbound-strands`。
- NUPACK 用户输入错误与后端输出错误分离；样本数、链种数、复合物大小、概率、浓度和目标比例均有边界检查。
- NUPACK tube 的目标比例分母显式保存，避免把“复合物浓度和”误写为投料链产率。
- 去除运行时 NUPACK 探测结果中的外部 URL，保持综合 HTML 报告完全本地；许可证限制仍以结构化字段记录。
- 明确 1 OD260 的定义、DNA 双链质量的反向互补假设，以及没有显式氢时只能报告 N/O 几何接触。

## 科学与后端边界

- 原生双链最近邻模型只覆盖完整互补 canonical DNA；Mg²⁺、错配和悬垂端需要显式 Primer3 后端。
- NUPACK 当前未安装；受控替身只验证 adapter 契约，不构成真实 NUPACK 数值验证。
- `1ehz-dssr-example.json` 是 RNA 字段架构夹具，不是 DNA 计算结果。
- 原生 PDB 螺旋参数、SASA 和体积是有方法标签的坐标近似；标准局部碱基对参数必须来自 3DNA/DSSR 等结果。
- 单个三维构象不能确定持久长度或弯曲、扭转、伸展刚度，相关字段保持 `conditional`。

## 1) assign

- **Purpose:** Document a reusable assign capability for Experimental design workflows. Candidate CAP-0158 comes from 15 source row(s) and is currently marked `review_needed`; the candidate keeps input-type, backend, format, platform, provider, assay, or biological-entity differences inside one typed interface rather than creating one function per variant.

- **Method:** Validate the typed input envelope, normalize records and metadata, perform the assign operation, and return structured results with provenance and diagnostics. The implementation is available at `src/dnakit/experimental_design/__init__.py` and is exported through the formal DNAKit namespace. Agent/MCP exposure is available when the function's JSON call plan is compatible. This is a local adapter: it validates the typed input and reports the backend required for scientific execution; it does not claim to replace that backend. Review basis: `merged_dimension`.

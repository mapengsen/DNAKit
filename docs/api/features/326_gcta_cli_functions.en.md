# GCTA: relationship matrices, REML, association and summary-statistics analyses

This group of functions in `dnakit.gwas` is a set of command-line facades over [GCTA](https://yanglab.westlake.edu.cn/software/gcta/) (Genome-wide Complex Trait Analysis, Yang Lab; released as a binary under the MIT licence). Each function runs one fixed GCTA analysis with an explicit argument list (no shell), refuses to overwrite an existing result, and returns a dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` (result key to file), `log_tail` and a small parsed `summary` of the main result file. `status` is `completed` only when the exit code is 0 and every expected output exists. Arguments left as `None` are not passed, so GCTA's own defaults apply. Genotypes are PLINK binary filesets. Tested with GCTA 1.95.4; the fastGWA-GE option `envir_file` needs 1.95 or later, and the `.cojo` file suffix of COJO results differs between 1.94 and 1.95 (both are recognised).

GCTA is an external program. Install it (a release binary, or `conda install -c bioconda gcta` for 1.94.1) and put `gcta64` on PATH or pass `gcta_path`; if it is missing the function raises `BackendUnavailableError` with an install hint. `gcta_simulate_phenotypes` draws new random numbers on each run, so its phenotypes differ between calls. The examples import from the module directly and call every function with `verbose=False`.

## Example data

The examples read the small files below. Every output is written to a fresh temporary directory because the functions never overwrite a file.

The only declared input is generated by the first step: a PLINK fileset `toy` of 200 samples and 2600 SNPs (chromosomes 1, 2 and X) drawn from a seeded random generator, a quantitative trait with 60 causal SNPs, a second correlated trait, a binary trait, covariate and environment files, and small SNP, gene and set lists.

- **Example code:**

```python
import numpy as np
from pathlib import Path

rng = np.random.default_rng(1)
samples, per_chromosome = 200, (1300, 1200, 100)
snps = sum(per_chromosome)
frequency = rng.uniform(0.1, 0.5, snps)
genotypes = rng.binomial(2, frequency, size=(samples, snps))
chromosomes = [1] * per_chromosome[0] + [2] * per_chromosome[1] + [23] * per_chromosome[2]
positions = [1000 * (k + 1) for count in per_chromosome for k in range(count)]
code = {0: 0b00, 1: 0b10, 2: 0b11}
with open("toy.bed", "wb") as handle:
    handle.write(bytes([0x6C, 0x1B, 0x01]))
    for j in range(snps):
        packed = bytearray((samples + 3) // 4)
        for i, value in enumerate(genotypes[:, j]):
            packed[i // 4] |= code[int(value)] << (2 * (i % 4))
        handle.write(bytes(packed))
Path("toy.bim").write_text("".join(f"{chromosomes[j]}\trs{j + 1}\t0\t{positions[j]}\tA\tG\n" for j in range(snps)))
Path("toy.fam").write_text("".join(f"F{i + 1} I{i + 1} 0 0 {1 + i % 2} -9\n" for i in range(samples)))
beta = np.zeros(snps)
causal = rng.choice(snps, 60, replace=False)
beta[causal] = rng.normal(0, 0.3, 60)
standardised = (genotypes - 2 * frequency) / np.sqrt(2 * frequency * (1 - frequency))
trait = standardised @ beta + rng.normal(0, 1.0, samples)
second = 0.5 * trait + rng.normal(0, 1.0, samples)
binary = (trait > np.median(trait)).astype(int)
covariate = rng.normal(0, 1.0, samples)
lines = {
    "toy.phen": [f"F{i + 1} I{i + 1} {trait[i]:.5f}" for i in range(samples)],
    "toy2.phen": [f"F{i + 1} I{i + 1} {trait[i]:.5f} {second[i]:.5f}" for i in range(samples)],
    "toy.bin.phen": [f"F{i + 1} I{i + 1} {binary[i]}" for i in range(samples)],
    "toy.qcovar": [f"F{i + 1} I{i + 1} {covariate[i]:.4f}" for i in range(samples)],
    "toy.envir": [f"F{i + 1} I{i + 1} {covariate[(i + 7) % samples]:.4f}" for i in range(samples)],
    "toy.env_class": [f"F{i + 1} I{i + 1} {i % 3}" for i in range(samples)],
    "toy.subpop": [f"F{i + 1} I{i + 1} {'PopA' if i % 2 == 0 else 'PopB'}" for i in range(samples)],
    "keep150.txt": [f"F{i + 1} I{i + 1}" for i in range(150)],
    "causal.snplist": ["rs5 0.1", "rs100 -0.2"],
    "ld.snplist": ["rs5", "rs100"],
    "joint.snplist": ["rs5", "rs100", "rs300"],
    "cond.snplist": ["rs5"],
    "genes.txt": ["1 1 400000 Gene1", "1 400001 800000 Gene2", "2 1 400000 Gene3"],
    "genes_burden.txt": ["gene chr start end strand", "G1 1 1 100000 +", "G2 1 200000 400000 +", "G3 2 1 300000 -"],
    "genes_acat.txt": ["1 1000 100000 G1", "1 200000 400000 G2", "2 1000 300000 G3"],
    "sets.txt": ["S1", "rs1", "rs2", "rs3", "rs4", "END", "S2", "rs10", "rs11", "rs12", "END"],
    "set1.snps": [f"rs{k}" for k in range(1, 301)],
    "set2.snps": [f"rs{k}" for k in range(301, 701)],
}
for name, content in lines.items():
    Path(name).write_text("\n".join(content) + "\n")
print(snps, samples, len(lines))
```

- **Example output:**

```text
2600 200 18
```

## 1) `dnakit.gwas.gcta_recode_standardized_genotypes()`

- **Purpose:** Write the standardised SNP genotype matrix of a PLINK fileset as compressed text (`gcta64 --recode-std`).
- **Method:** Each genotype is standardised as (x - 2p) / sqrt(2p(1-p)) with p the allele frequency estimated from the data. The matrix is written to `<out_prefix>.xmat.gz`; `n_individuals` and `n_snps` come from GCTA's log.
- **API:** `dnakit.gwas.gcta_recode_standardized_genotypes(bfile, out_prefix, *, keep=None, extract=None, chromosome=None, maf=None, max_maf=None, threads=None, ..., verbose=True)`.
- **Input:** A PLINK prefix and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `n_individuals` and `n_snps`; the matrix is `<prefix>.xmat.gz`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_recode_standardized_genotypes
import gzip

result = gcta_recode_standardized_genotypes("toy", str(out / "rs"), chromosome=1, verbose=False)
with gzip.open(result["outputs"]["xmat"], "rt") as handle:
    rows = [line.split() for line in handle]
print(result["status"], result["n_individuals"], result["n_snps"], len(rows) - 2)
```

- **Example output:**

```text
completed 200 1300 200
```

## 2) `dnakit.gwas.gcta_make_grm()`

- **Purpose:** Compute a dense genetic relationship matrix (GRM) from SNP genotypes and save it in binary format (`gcta64 --make-grm*`).
- **Method:** `grm_type` selects the matrix: `autosome` (`--make-grm`, the additive GRM of the autosomal SNPs), `xchr` (`--make-grm-xchr`, the GRM of the X chromosome), `dominance` (`--make-grm-d`, the dominance GRM, written as `<out_prefix>.d.grm.*`) or `inbred` (`--autosome --make-grm-inbred`, the GRM for an inbred population). Give genotypes as one PLINK prefix `bfile` or a list file `mbfile` of per-chromosome prefixes. The files `<out_prefix>.grm.bin`, `.grm.N.bin` and `.grm.id` are written; `grm_prefix` is the prefix to pass on.
- **API:** `dnakit.gwas.gcta_make_grm(out_prefix, *, bfile=None, mbfile=None, grm_type='autosome', keep=None, extract=None, chromosome=None, ..., verbose=True)`.
- **Input:** A PLINK prefix (`bfile`) or a list file of prefixes (`mbfile`), a new output prefix and `grm_type`.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `grm_prefix` and `n_individuals`; files `.grm.bin`, `.grm.N.bin`, `.grm.id`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_make_grm
import struct

result = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)
raw = Path(result["grm_prefix"] + ".grm.bin").read_bytes()
values = struct.unpack(f"<{len(raw) // 4}f", raw)
diagonal = [values[i * (i + 1) // 2 + i] for i in range(200)]
print(result["status"], result["n_individuals"], len(values), round(sum(diagonal) / 200, 2))
dominance = gcta_make_grm(str(out / "d"), bfile="toy", grm_type="dominance", verbose=False)
print(Path(dominance["grm_prefix"]).name, sorted(Path(p).name for p in dominance["outputs"].values() if "grm" in p))
```

- **Example output:**

```text
completed 200 20100 1.0
d.d ['d.d.grm.N.bin', 'd.d.grm.bin', 'd.d.grm.id']
```

## 3) `dnakit.gwas.gcta_make_sparse_grm()`

- **Purpose:** Threshold a dense GRM into a sparse GRM for fastGWA (`gcta64 --grm P --make-bK-sparse` or `--make-bK`).
- **Method:** Off-diagonal elements below `cutoff` (GCTA's recommended 0.05) are set to zero. `output_format="sparse"` (`--make-bK-sparse`) writes `<out_prefix>.grm.sp` and `.grm.id`, the format `--grm-sparse` reads; `output_format="dense"` (`--make-bK`) writes the same thresholded matrix as a binary GRM (`.grm.bin`, `.grm.N.bin`, `.grm.id`). `n_pairs` counts the retained pairs of the sparse file.
- **API:** `dnakit.gwas.gcta_make_sparse_grm(grm_prefix, out_prefix, *, cutoff=0.05, output_format='sparse', gcta_path=None, timeout_seconds=3600.0, verbose=True)`.
- **Input:** A GRM prefix, a new output prefix and `cutoff` (default 0.05).
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `n_pairs` of the sparse file `<prefix>.grm.sp`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_make_grm, gcta_make_sparse_grm

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
sparse = gcta_make_sparse_grm(grm, str(out / "sp"), cutoff=0.05, verbose=False)
print(sparse["status"], sparse["n_pairs"], Path(sparse["outputs"]["grm_sp"]).name)
dense = gcta_make_sparse_grm(grm, str(out / "bk"), output_format="dense", verbose=False)
print(sorted(Path(p).name for k, p in dense["outputs"].items() if k != "log"))
```

- **Example output:**

```text
completed 255 sp.grm.sp
['bk.grm.N.bin', 'bk.grm.bin', 'bk.grm.id']
```

- **Input:** A PLINK prefix and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` with the number of individuals and the mean of each estimate.

```python
import tempfile
```

## 5) `dnakit.gwas.gcta_unify_grm()`

- **Purpose:** Restrict several GRMs to the individuals they have in common, in the same order (`gcta64 --mgrm list --unify-grm`).
- **Method:** GCTA names and places the unified matrices by itself (`<input>_<out name>` next to the input), so this function runs it on links to the inputs in a scratch folder and moves the results to stable names: `<out_prefix>.1.grm.bin` / `.grm.id` for the first input, `<out_prefix>.2...` for the second and so on. Those prefixes are listed in `unified` and can be passed to `gcta_reml`. `common_individuals` is the number of individuals kept.
- **API:** `dnakit.gwas.gcta_unify_grm(grm_prefixes, out_prefix, *, gcta_path=None, timeout_seconds=3600.0, verbose=True)`.
- **Input:** At least two GRM prefixes and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `unified`: the new GRM prefixes, and `common_individuals`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_make_grm, gcta_unify_grm

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
subset = gcta_make_grm(str(out / "s"), bfile="toy", keep="keep150.txt", verbose=False)["grm_prefix"]
result = gcta_unify_grm([grm, subset], str(out / "un"), verbose=False)
print(result["status"], result["common_individuals"], [Path(p).name for p in result["unified"]])
```

- **Example output:**

```text
completed 150 ['un.1', 'un.2']
```

## 6) `dnakit.gwas.gcta_reml()`

- **Purpose:** Estimate variance components and SNP-based heritability by GREML, optionally with GxE or genetic-value prediction (`gcta64 --reml`).
- **Method:** `grm_prefix` is one GRM; `grm_prefixes` fits several GRMs (`--mgrm`). `phenotype_file` has columns FID, IID and the phenotype(s); `phenotype_column` (`--mpheno`) picks the n-th phenotype. `gxe_file` (`--gxe`) adds a genotype-by-environment variance component from a discrete environment factor. `predict` is `none`, `blup` (`--reml-pred-rand`: BLUP of every individual's total genetic value, written to `<out_prefix>.indi.blp`) or `cvblup` (`--cvblup`: leave-one-out BLUP, `<out_prefix>.indi.cvblp`). `no_constrain` lets components leave the parameter space (`--reml-no-constrain`); `prevalence` transforms the heritability of a binary trait to the liability scale. The `.hsq` file is parsed into `variance_components` (source, variance, SE) and `statistics` (logL, logL0, LRT, df, Pval, n).
- **API:** `dnakit.gwas.gcta_reml(phenotype_file, out_prefix, *, grm_prefix=None, grm_prefixes=None, phenotype_column=None, covariate_file=None, quantitative_covariate_file=None, gxe_file=None, ..., verbose=True)`.
- **Input:** One GRM (`grm_prefix`) or several (`grm_prefixes`), a phenotype file and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` with `variance_components` and `statistics`; `n_predictions` for BLUP.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_make_grm, gcta_reml

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
result = gcta_reml("toy.phen", str(out / "r"), grm_prefix=grm, predict="blup", verbose=False)
for row in result["summary"]["variance_components"]:
    print(row["source"], round(row["variance"], 3), round(row["se"], 3))
print(result["summary"]["statistics"]["n"], result["n_predictions"])
gxe = gcta_reml("toy.phen", str(out / "gxe"), grm_prefix=grm, gxe_file="toy.env_class", verbose=False)
print([row["source"] for row in gxe["summary"]["variance_components"]][:3])
```

- **Example output:**

```text
V(G) 1.877 2.179
V(e) 4.319 2.169
Vp 6.196 0.623
V(G)/Vp 0.303 0.348
200 200
['V(G)', 'V(GxE)', 'V(e)']
```

## 7) `dnakit.gwas.gcta_blup_snp()`

- **Purpose:** Convert the BLUP of individuals' genetic values into BLUP effects of every SNP (`gcta64 --blup-snp`).
- **Method:** `indi_blp_file` is the `.indi.blp` file written by `gcta_reml(predict='blup')`. The SNP effects (`<out_prefix>.snp.blp`: SNP, reference allele, one effect per fitted GRM) can be used to score new samples. `autosome=True` restricts the SNPs to chromosomes 1 to 22, which GCTA needs when the fileset has sex chromosomes.
- **API:** `dnakit.gwas.gcta_blup_snp(bfile, indi_blp_file, out_prefix, *, autosome=False, keep=None, extract=None, threads=None, gcta_path=None, timeout_seconds=3600.0, verbose=True)`.
- **Input:** A PLINK prefix, the `.indi.blp` file and a new output prefix (`autosome=True` if the fileset has sex chromosomes).
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `n_snps`; effects in `<prefix>.snp.blp`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_blup_snp, gcta_make_grm, gcta_reml

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
blup = gcta_reml("toy.phen", str(out / "r"), grm_prefix=grm, predict="blup", verbose=False)
result = gcta_blup_snp("toy", blup["outputs"]["indi_blp"], str(out / "bs"), autosome=True, verbose=False)
print(result["status"], result["n_snps"])
print(gcta_blup_snp("toy", blup["outputs"]["indi_blp"], str(out / "bs2"), verbose=False)["status"])
```

## 9) `dnakit.gwas.gcta_he_regression()`

- **Purpose:** Haseman-Elston regression for SNP-based heritability or, with `bivariate=True`, genetic correlation (`gcta64 --HEreg` / `--HEreg-bivar`).
- **Method:** `bivariate=False` regresses the cross products (HE-CP) and squared differences (HE-SD) of one phenotype (`phenotype_column` = `--mpheno`) on the GRM. `bivariate=True` uses the two traits named by `trait_columns` (default `[1, 2]`) and reports their genetic correlation (rG). `summary` parses `<out_prefix>.HEreg` into the `HE-CP` and `HE-SD` tables of coefficient, estimate, OLS and jackknife standard errors and p-values.
- **API:** `dnakit.gwas.gcta_he_regression(phenotype_file, out_prefix, *, grm_prefix=None, grm_prefixes=None, bivariate=False, trait_columns=(1, 2), phenotype_column=None, keep=None, ..., verbose=True)`.
- **Input:** A GRM, a phenotype file and a new output prefix; `bivariate=True` for two traits.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` with the `HE-CP` and `HE-SD` tables.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_he_regression, gcta_make_grm

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
he = gcta_he_regression("toy.phen", str(out / "he"), grm_prefix=grm, verbose=False)
print(sorted(he["summary"]), [row["coefficient"] for row in he["summary"]["HE-CP"]])
pair = gcta_he_regression("toy2.phen", str(out / "hb"), grm_prefix=grm, bivariate=True, verbose=False)
print([row["coefficient"] for row in pair["summary"]["HE-CP"]][-3:])
```

- **Example output:**

```text
['HE-CP', 'HE-SD'] ['Intercept', 'V(G)/Vp']
['rG', 'N_tr1', 'N_tr2']
```

## 10) `dnakit.gwas.gcta_fastgwa()`

- **Purpose:** fastGWA association tests of every SNP (`gcta64 --fastGWA-mlm` / `--fastGWA-mlm-exact` / `--fastGWA-mlm-binary` / `--fastGWA-lr`).
- **Method:** `model` selects the analysis: `mlm` (mixed linear model with a sparse GRM and the GRAMMAR-Gamma approximation), `mlm_exact` (the exact test without GRAMMAR-Gamma), `mlm_binary` (fastGWA-GLMM for a binary trait coded 0/1; needs at least 2000 autosomal SNPs for tuning and is slow without covariates) or `lr` (linear regression, no sparse GRM). The three mixed models need `sparse_grm_prefix` (see `gcta_make_sparse_grm`). `envir_file` (FID, IID, continuous environment value; GCTA 1.95 or later) turns `mlm` or `lr` into the fastGWA-GE genotype-by-environment interaction test. `model_only=True` stops after variance-component estimation and saves the model (`<out_prefix>.fastGWA.mdl.bin2`/`.mdl.id`) for `gcta_fastgwa_burden`. The statistics table `<out_prefix>.fastGWA` is summarised in `summary` (row count, columns, smallest-p rows).
- **API:** `dnakit.gwas.gcta_fastgwa(phenotype_file, out_prefix, *, bfile=None, mbfile=None, model='mlm', sparse_grm_prefix=None, covariate_file=None, quantitative_covariate_file=None, ..., verbose=True)`.
- **Input:** Phenotype file, output prefix, genotypes and, for the mixed models, a sparse GRM.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` of `<prefix>.fastGWA` (rows, columns and the smallest-p rows).
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_fastgwa, gcta_make_grm, gcta_make_sparse_grm

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
```

## 14) `dnakit.gwas.gcta_cojo()`

- **Purpose:** Conditional and joint multiple-SNP analysis of GWAS summary statistics, using a genotype fileset as the LD reference (`gcta64 --cojo-slct` / `--cojo-cond` / `--cojo-joint`).
- **Method:** `summary_file` is a COJO `.ma` file with the columns SNP, A1, A2, freq, b, se, p, N (give statistics for all SNPs; restrict the analysis with `extract`/`chromosome`). `mode='slct'` selects independent signals by stepwise regression (`p_threshold`, default 5e-8; `top_snps` instead selects a fixed number without a threshold); `mode='joint'` fits all included SNPs jointly; `mode='cond'` tests every SNP conditional on the SNPs in `snp_list_file`. `window_kb` (default 10000) is the distance beyond which SNPs are in linkage equilibrium, `collinearity` the R-squared cut-off (default 0.9), `diff_freq` the largest allowed frequency difference to the reference (default 0.2); `genomic_control=True` (or a value such as 1.05) adjusts the p-values. Results: `jma` (selected or joint effects) and `ldr` (their LD matrix) for `slct`/`joint`, `cma` (conditional effects) for `cond` and, with `slct`, for the remaining SNPs.
- **API:** `dnakit.gwas.gcta_cojo(bfile, summary_file, out_prefix, *, mode='slct', snp_list_file=None, top_snps=None, p_threshold=None, window_kb=None, collinearity=None, ..., verbose=True)`.
- **Input:** Genotypes (LD reference), a COJO `.ma` summary file, a new output prefix and `mode`.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` of the `.jma` (or `.cma`) table.
- **Example code:**


## 20) `dnakit.gwas.gcta_gsmr()`

- **Purpose:** Generalised summary-data-based Mendelian randomisation between exposures and outcomes (`gcta64 --gsmr-file`).
- **Method:** `exposure_list_file` and `outcome_list_file` list traits (name and summary-statistics file in COJO format, one per row). `direction` is 0 (forward, default), 1 (reverse) or 2 (bidirectional). The SNP instruments are clumped at `gwas_thresh` (default 5e-8) and `clump_r2` (default 0.05); `heidi_thresh` (default 0.01) removes pleiotropic outliers and `gsmr2=True` uses the new global HEIDI-outlier method of GSMR2; `snp_min` (default 10) is the minimum number of instruments and `ld_fdr` (default 0.05) shrinks chance LD between instruments. `<out_prefix>.gsmr` holds exposure, outcome, bxy, se, p and the number of SNPs (`summary`); `effect_plot` also saves the data for the SNP-effect plot (`.eff_plot.gz`).
- **API:** `dnakit.gwas.gcta_gsmr(exposure_list_file, outcome_list_file, out_prefix, *, bfile=None, mbfile=None, direction=0, gsmr2=False, diff_freq=None, gwas_thresh=None, ..., verbose=True)`.
- **Input:** Genotypes (LD reference), exposure and outcome list files, and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `summary` of `<prefix>.gsmr` (exposure, outcome, bxy, se, p, nsnp).
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_gsmr, gcta_make_grm, gcta_mlma

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
ml = gcta_mlma("toy", "toy.phen", str(out / "ml"), grm_prefix=grm, verbose=False)
rows = [line.split() for line in Path(ml["outputs"]["mlma"]).read_text().splitlines()[1:]]
(out / "ml.ma").write_text("SNP A1 A2 freq b se p N\n" + "\n".join(" ".join([r[1], r[3], r[4], r[5], r[6], r[7], r[8], "200"]) for r in rows) + "\n")
lines = (out / "ml.ma").read_text().splitlines()
(out / "exp.ma").write_text(lines[0] + "\n" + "\n".join(" ".join(l.split()[:4] + [str(float(l.split()[4]) * 0.5 + 0.01)] + l.split()[5:]) for l in lines[1:]) + "\n")
(out / "expo.txt").write_text(f"bmi {out / 'exp.ma'}\n")
(out / "outc.txt").write_text(f"t2d {out / 'ml.ma'}\n")
result = gcta_gsmr(str(out / "expo.txt"), str(out / "outc.txt"), str(out / "gs"), bfile="toy", snp_min=3, gwas_thresh=0.05, clump_r2=0.5, heidi_thresh=0.0, verbose=False)
row = result["summary"]["top_rows"][0]
print(row["Exposure"], row["Outcome"], row["nsnp"], row["bxy"] > 0)
```

## 25) `dnakit.gwas.gcta_project_loading()`

- **Purpose:** Project the samples of a fileset onto reference SNP loadings to obtain their principal components (`gcta64 --project-loading`).
- **Method:** `loading_prefix` is the prefix of the `<prefix>.pcl` file made by `gcta_pc_loading`; only the SNPs shared with the reference are used. `n_components` PCs are written (default 20, at most the number computed for the reference) to `<out_prefix>.proj.eigenvec` (FID, IID, PC1 ...). By default loadings use the reference allele frequencies; `update_freq_file` (`--update-freq`) supplies other frequencies.
- **API:** `dnakit.gwas.gcta_project_loading(bfile, loading_prefix, out_prefix, *, n_components=20, autosome=True, update_freq_file=None, keep=None, extract=None, threads=None, ..., verbose=True)`.
- **Input:** Genotypes, the prefix of the `.pcl` file and a new output prefix.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `n_individuals`; PCs in `<prefix>.proj.eigenvec`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_make_grm, gcta_pc_loading, gcta_project_loading
import subprocess

grm = gcta_make_grm(str(out / "g"), bfile="toy", verbose=False)["grm_prefix"]
subprocess.run(["gcta64", "--grm", grm, "--pca", "5", "--out", str(out / "pc")], check=True, capture_output=True)
gcta_pc_loading("toy", str(out / "pc"), str(out / "pl"), verbose=False)
result = gcta_project_loading("toy", str(out / "pl"), str(out / "proj"), n_components=5, verbose=False)
reference = [float(line.split()[2]) for line in Path(str(out / "pc") + ".eigenvec").read_text().splitlines()]
projected = [float(line.split()[2]) for line in Path(result["outputs"]["eigenvec"]).read_text().splitlines()]
mx, my = sum(reference) / 200, sum(projected) / 200
cov = sum((a - mx) * (b - my) for a, b in zip(reference, projected))
corr = cov / (sum((a - mx) ** 2 for a in reference) ** 0.5 * sum((b - my) ** 2 for b in projected) ** 0.5)
print(result["n_individuals"], round(abs(corr), 3))
```

- **Example output:**

```text
200 1.0
```

## 27) `dnakit.gwas.gcta_simulate_phenotypes()`

- **Purpose:** Simulate phenotypes from real genotypes with chosen causal variants (`gcta64 --simu-qt` / `--simu-cc`).
- **Method:** `trait='quantitative'` simulates a quantitative trait; `trait='case_control'` simulates `n_cases` cases and `n_controls` controls from the liability model (at most n*K cases and n*(1-K) controls, K = `prevalence`, default 0.1). `causal_loci_file` lists causal SNPs with optional effect sizes (columns SNP, effect; effects are drawn from a standard normal when absent, and so are the loci when the file is omitted). `heritability` (default 0.1; of the liability for case-control) and `replicates` (default 1) shape the simulation. GCTA draws new random numbers on every run (its `--simu-seed` does not make runs repeat), so results differ between calls. `<out_prefix>.phen` holds FID, IID and one column per replicate (missing -9 for individuals that were not sampled in a case-control study); `<out_prefix>.par` holds the causal variants (QTL, RefAllele, Frequency, Effect).
- **API:** `dnakit.gwas.gcta_simulate_phenotypes(bfile, out_prefix, *, trait='quantitative', n_cases=None, n_controls=None, causal_loci_file=None, heritability=None, prevalence=None, ..., verbose=True)`.
- **Input:** Genotypes, a new output prefix, the trait kind and the causal loci file.
- **Output:** A dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`, plus `causal_variants` and `n_individuals`; phenotypes in `<prefix>.phen`.
- **Example code:**

```python
import tempfile
from pathlib import Path

out = Path(tempfile.mkdtemp())
from dnakit.gwas.gcta_p08_cli_functions import gcta_simulate_phenotypes

q = gcta_simulate_phenotypes("toy", str(out / "q"), causal_loci_file="causal.snplist", heritability=0.5, replicates=2, verbose=False)
print(q["n_individuals"], q["causal_variants"])

```

# Sequencing QC adapter, UMI, and SLOW5 signal backends

This group of functions in `dnakit.sequencing_qc` is a set of adapters over optional packages. Adapter alignment, FASTQ adapter trimming, and quality trimming use the Python API of [cutadapt](https://github.com/marcelm/cutadapt); FASTQ reading and writing use its dependency [dnaio](https://github.com/marcelm/dnaio); UMI clustering, barcode extraction, and whitelist correction use [umi-tools](https://github.com/CGATOxford/UMI-tools); raw signal reading and writing use [pyslow5](https://github.com/hasindu2008/slow5lib). Every function works only on explicit sequences, files, and records. None downloads reference data or calls a command line. They compute adapter positions, trimming results, quality-trim intervals, expected error counts, UMI clusters, extracted barcodes, whitelist mappings, and SLOW5/BLOW5 signal statistics, reads, and writes. They do not perform base calling or alignment.

The dependencies are optional and are imported only when the matching function is called. If a package is missing, the function raises an error that includes the install command.

## Example data

The FASTQ below has 3 reads and demonstrates adapter trimming. `r1` has the 3' adapter `AGATCGGAAGAGC`, `r3` is entirely adapter, and `r2` contains no adapter. The SLOW5 signal data is generated by the example code itself.

**Example file:** `reads.fastq`

```text
@r1
ACGTTTACGTAGATCGGAAGAGCTTT
+
IIIIIIIIIIIIIIIIIIIIIIIIII
@r2
GGGGGGGGGGGGGGGG
+
IIIIIIIIIIIIIIII
@r3
AGATCGGAAGAGCACGT
+
IIIIIIIIIIIIIIIII
```

## 1) `dnakit.sequencing_qc.find_adapter_match()`

- **Purpose:** Locate one adapter in a DNA sequence and return the trimmed sequence.
- **Method:** Uses cutadapt's adapter aligner. It supports 3' adapters (`"3prime"`), 5' adapters (`"5prime"`), and adapters at any position (`"anywhere"`). `max_errors` is the allowed error rate, and `min_overlap` is the shortest overlap. Coordinates are 0-based and half-open.
- **API:** `dnakit.sequencing_qc.find_adapter_match(sequence, adapter, *, position="3prime", max_errors=0.1, min_overlap=3)`.
- **Input:** A DNA sequence and an adapter sequence. Only ACGT and IUPAC ambiguity codes are allowed. `max_errors` must be in [0, 1).
- **Output:** A dictionary with `matched`, `start`, `stop`, `errors`, `score`, `trimmed_sequence`, and `provenance`. When there is no match, the coordinates are `None` and the trimmed sequence equals the input.
- **Example code:**

```python
from dnakit.sequencing_qc import find_adapter_match

result = find_adapter_match("ACGTTTACGTAGATCGGAAGAGCTTT", "AGATCGGAAGAGC")
print(result["matched"], result["start"], result["stop"], result["errors"])
print(result["trimmed_sequence"])
```

- **Example output:**

```text
True 10 23 0
ACGTTTACGT
```

## 2) `dnakit.sequencing_qc.trim_fastq_adapters()`

- **Purpose:** Trim the same adapter from every read in a FASTQ file and write the reads that remain to a new file.
- **Method:** Trims each read with cutadapt's `AdapterCutter`, and reads and writes FASTQ with dnaio. Reads shorter than `minimum_length` after trimming are discarded and counted.
- **API:** `dnakit.sequencing_qc.trim_fastq_adapters(source, output, adapter, *, position="3prime", max_errors=0.1, min_overlap=3, minimum_length=1, max_reads=1000000)`.
- **Input:** A FASTQ path `source`. `output` must be a file that does not exist yet. `max_reads` is an explicit limit; exceeding it raises an error and removes the unfinished output.
- **Output:** `reads`, `reads_with_adapter`, `reads_written`, `reads_too_short`, `bases_removed` (the total number of bases removed), and `provenance`.
- **Example code:**

```python
import tempfile
from pathlib import Path
from dnakit.sequencing_qc import trim_fastq_adapters

with tempfile.TemporaryDirectory() as directory:
    result = trim_fastq_adapters("reads.fastq", Path(directory) / "trimmed.fastq", "AGATCGGAAGAGC")
    print({key: result[key] for key in ("reads", "reads_with_adapter", "reads_written", "reads_too_short", "bases_removed")})
```

- **Example output:**

```text
{'reads': 3, 'reads_with_adapter': 2, 'reads_written': 2, 'reads_too_short': 1, 'bases_removed': 33}
```

## 3) `dnakit.sequencing_qc.find_quality_trim_bounds()`

- **Purpose:** Return the interval that remains after quality trimming.
- **Method:** Uses cutadapt's `quality_trim_index` (the BWA algorithm). From each end it accumulates `cutoff - Q`, and the position with the largest running sum is the trim point.
- **API:** `dnakit.sequencing_qc.find_quality_trim_bounds(qualities, *, cutoff_front=0, cutoff_back=20, phred_offset=33)`.
- **Input:** A Phred quality string. `cutoff_front` and `cutoff_back` must be in [0, 93]. `phred_offset` is 33 or 64.
- **Output:** `length`, `start`, `stop` (0-based, half-open), `retained_length`, and `provenance`.
- **Example code:**

```python
from dnakit.sequencing_qc import find_quality_trim_bounds

result = find_quality_trim_bounds("IIII!!!!", cutoff_back=20)
print(result["start"], result["stop"], result["retained_length"])
```

- **Example output:**

```text
0 4 4
```

## 4) `dnakit.sequencing_qc.calculate_expected_errors()`

- **Purpose:** Compute the expected number of errors in one read.
- **Method:** Each base contributes 10^(−Q/10). The sum is computed by cutadapt's `expected_errors`.
- **API:** `dnakit.sequencing_qc.calculate_expected_errors(qualities, *, phred_offset=33)`.
- **Input:** A Phred quality string. `phred_offset` is 33 or 64.
- **Output:** `length`, `expected_errors`, and `provenance`.
- **Example code:**

```python
from dnakit.sequencing_qc import calculate_expected_errors

result = calculate_expected_errors("++II")
print(round(result["expected_errors"], 4))
```

- **Example output:**

```text
0.2002
```

## 5) `dnakit.sequencing_qc.write_slow5_signals()`

- **Purpose:** Write raw signal records to a new SLOW5 (`.slow5`) or BLOW5 (`.blow5`) file.
- **Method:** Uses pyslow5's writer for a single read group. All records must share one sampling rate, which is written to the `sample_frequency` header field. The file format follows the output file's suffix.
- **API:** `dnakit.sequencing_qc.write_slow5_signals(records, output, *, max_reads=100000)`.
- **Input:** A list of records. Each record has `read_id`, `signal` (a list of integers in the int16 range), `digitisation`, `offset`, `range`, and `sampling_rate`. `output` must not exist yet.
- **Output:** `reads_written`, `signal_samples_written`, `sampling_rate`, `output`, and `provenance`.
- **Example code:**

```python
import tempfile
from pathlib import Path
from dnakit.sequencing_qc import write_slow5_signals

common = {"digitisation": 8192.0, "offset": 10.0, "range": 1443.0, "sampling_rate": 4000.0}
records = [
    {"read_id": "r1", "signal": [500, 510, 520, 530], **common},
    {"read_id": "r2", "signal": [100, 200, 300], **common},
]
with tempfile.TemporaryDirectory() as directory:
    result = write_slow5_signals(records, Path(directory) / "signals.slow5")
    print(result["reads_written"], result["signal_samples_written"])
```

- **Example output:**

```text
2 7
```

## 6) `dnakit.sequencing_qc.summarize_slow5_signals()`

- **Purpose:** Count reads, signal samples, and sampling rates in a SLOW5 or BLOW5 file.
- **Method:** Scans the file once, sequentially (`seq_reads`), and does not create an index next to the input. Raises an error if the number of reads exceeds `max_reads`.
- **API:** `dnakit.sequencing_qc.summarize_slow5_signals(source, *, max_reads=100000)`.
- **Input:** A `.slow5` or `.blow5` file path. A file whose suffix or header magic does not match is rejected before pyslow5 opens it.
- **Output:** `reads`, `read_groups`, `signal_samples`, `min_signal_samples`, `mean_signal_samples`, `max_signal_samples`, `sampling_rates`, `header_sample_frequency`, and `provenance`.
- **Example code:**

```python
import tempfile
from pathlib import Path
from dnakit.sequencing_qc import summarize_slow5_signals, write_slow5_signals

common = {"digitisation": 8192.0, "offset": 10.0, "range": 1443.0, "sampling_rate": 4000.0}
records = [
    {"read_id": "r1", "signal": [500, 510, 520, 530], **common},
    {"read_id": "r2", "signal": [100, 200, 300], **common},
]
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory) / "signals.slow5"
    write_slow5_signals(records, path)
    summary = summarize_slow5_signals(path)
    print(summary["reads"], summary["signal_samples"], summary["mean_signal_samples"], summary["sampling_rates"])
```

- **Example output:**

```text
2 7 3.5 [4000.0]
```

## 7) `dnakit.sequencing_qc.read_slow5_signal()`

- **Purpose:** Read the raw signal of one read, optionally converted to pA.
- **Method:** Scans sequentially until `read_id` is found, without building an index. With `pA=True`, pyslow5 converts the values as `(raw + offset) × range / digitisation`, and the result keeps 7 significant digits.
- **API:** `dnakit.sequencing_qc.read_slow5_signal(source, read_id, *, pA=False, max_reads=100000, max_samples=100000)`.
- **Input:** A file path and a `read_id` without whitespace. `max_samples` limits the signal length of one read; a longer read raises an error.
- **Output:** `read_id`, `read_group`, `units` (`"raw DAC"` or `"pA"`), `length`, `digitisation`, `offset`, `range`, `sampling_rate`, `signal`, and `provenance`.
- **Example code:**

```python
import tempfile
from pathlib import Path
from dnakit.sequencing_qc import read_slow5_signal, write_slow5_signals

common = {"digitisation": 8192.0, "offset": 10.0, "range": 1443.0, "sampling_rate": 4000.0}
records = [
    {"read_id": "r1", "signal": [500, 510, 520, 530], **common},
    {"read_id": "r2", "signal": [100, 200, 300], **common},
]
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory) / "signals.slow5"
    write_slow5_signals(records, path)
    raw = read_slow5_signal(path, "r2")
    picoamps = read_slow5_signal(path, "r1", pA=True)
    print(raw["signal"], picoamps["units"], picoamps["signal"])
```

- **Example output:**

```text
[100, 200, 300] pA [89.83521, 91.59668, 93.35815, 95.11963]
```

## 8) `dnakit.sequencing_qc.cluster_umi_counts()`

- **Purpose:** Cluster UMIs by Hamming distance. The representative of each cluster is its most frequent UMI.
- **Method:** Uses umi-tools' `UMIClusterer`. The `directional` method merges a child UMI into a parent only when the parent count is at least twice the child count minus one. `adjacency` uses distance alone, `cluster` merges connected components, and `unique` merges nothing. Distances are umi-tools' Hamming distances.
- **API:** `dnakit.sequencing_qc.cluster_umi_counts(umi_counts, *, method="directional", max_distance=1, max_umis=10000)`.
- **Input:** `umi_counts` is a `{UMI: positive integer count}` mapping. All UMIs have the same length and contain only A, C, G, T, and N. `method` is `"directional"`, `"adjacency"`, `"cluster"`, or `"unique"`. `max_distance` is between 0 and 5.
- **Output:** `clusters` (each cluster is a list of UMIs with the representative first), `representatives`, `cluster_counts` (the summed count of each cluster), `umis`, `umi_length`, and `provenance`.
- **Example code:**

```python
from dnakit.sequencing_qc import cluster_umi_counts

result = cluster_umi_counts({"AAAA": 10, "AAAT": 3, "CCCC": 5, "AAAC": 1})
print(result["clusters"])
print(result["cluster_counts"])
```

- **Example output:**

```text
[['AAAA', 'AAAT', 'AAAC'], ['CCCC']]
[14, 5]
```

## 9) `dnakit.sequencing_qc.extract_read_barcodes()`

- **Purpose:** Extract the cell barcode and UMI from one read with a regular expression, and return the read with those bases removed.
- **Method:** Uses umi-tools' `ExtractBarcodes`. The named group `cell_<n>` is the cell barcode, `umi_<n>` is the UMI, and `discard_<n>` marks bases to drop when `discard=True`. The expression is matched from the start of the read, and every barcode group must take part in the match. umi-tools does not return cell-barcode qualities, so only UMI qualities are reported.
- **API:** `dnakit.sequencing_qc.extract_read_barcodes(sequence, qualities, pattern, *, discard=True)`.
- **Input:** A DNA sequence, a Phred+33 quality string of the same length, and a regular expression string of at most 1000 characters.
- **Output:** `matched`, `cell_barcode`, `umi`, `umi_qualities`, `read_sequence`, `read_qualities`, and `provenance`. When there is no match, both barcodes are empty strings and the read is unchanged.
- **Example code:**

```python
from dnakit.sequencing_qc import extract_read_barcodes

read = "ACGTTTAGCCATTGGGAAA"
pattern = r"^(?P<cell_1>.{4})(?P<umi_1>.{3})(?P<discard_1>.{2})"
result = extract_read_barcodes(read, "I" * len(read), pattern)
print(result["cell_barcode"], result["umi"], result["umi_qualities"], result["read_sequence"])
```

- **Example output:**

```text
ACGT TTA III CATTGGGAAA
```

## 10) `dnakit.sequencing_qc.map_barcodes_to_whitelist()`

- **Purpose:** Correct observed cell barcodes to a whitelist, accepting only unique near matches.
- **Method:** Uses umi-tools' `getErrorCorrectMapping`, which matches by Hamming distance with a threshold of 1 to 3. A non-whitelisted barcode is assigned only when exactly one whitelisted barcode lies within the threshold. Barcodes with no candidate or several candidates go into `unassigned_barcodes`. Barcodes already on the whitelist count toward `exact_matches`.
- **API:** `dnakit.sequencing_qc.map_barcodes_to_whitelist(observed, whitelist, *, threshold=1, max_barcodes=100000)`.
- **Input:** A list of observed DNA barcodes and a whitelist. All barcodes have the same length and contain only A, C, G, and T.
- **Output:** `corrected` (a mapping from each whitelisted barcode to the observed barcodes corrected to it), `corrected_barcodes`, `exact_matches`, `observed_unique`, `unassigned_barcodes`, and `provenance`.
- **Example code:**

```python
from dnakit.sequencing_qc import map_barcodes_to_whitelist

result = map_barcodes_to_whitelist(
    ["AAAT", "AAAG", "CCCA", "GGGG", "TTTT"], ["AAAA", "CCCC", "GGGG"]
)
print(result["corrected"])
print(result["unassigned_barcodes"])
```

- **Example output:**

```text
{'AAAA': ['AAAG', 'AAAT'], 'CCCC': ['CCCA']}
['TTTT']
```

## How these functions are verified

The test file is `others/tests/unit/test_sequencing_backends.py`, with 32 tests. The main checks are:

- Adapter coordinates, error counts, and trimmed sequences agree with hand calculations. The 3' and 5' positions, `anywhere` position, and the effect of the error rate are all checked.
- Adapter coordinates agree with a direct call to cutadapt's `BackAdapter.match_to`.
- FASTQ trimming read counts, discard counts, and removed base counts agree with hand calculations, and the output file is compared line by line. Exceeding `max_reads` raises an error and removes the unfinished output. An existing output file is never overwritten.
- Quality-trim intervals and expected error counts agree with the hand formula `10^(-Q/10)`.
- SLOW5 read counts, signal sample counts, and the pA conversion agree with hand calculations. Summary statistics agree with a direct pyslow5 sequential scan. `.blow5` output round-trips, and no index file is created.
- A missing cutadapt, pyslow5, or umi-tools package gives an install hint. Out-of-range signal values, duplicate `read_id` values, mixed sampling rates, and files without a SLOW5 header are rejected.
- UMI clustering agrees with a hand calculation of the `directional` rule: `AAAA` with count 10 absorbs `AAAT` with count 3 and `AAAC` with count 1. Two UMIs with counts of 3 stay separate under `directional` and merge under `adjacency`. Results agree with a direct call to umi-tools' `UMIClusterer`.
- Barcode extraction agrees with a hand split of the read and with a direct call to umi-tools' `ExtractBarcodes`. A read without a match is returned unchanged. Missing barcode groups and invalid expressions are rejected.
- Whitelist correction agrees with a hand calculation and with a direct call to `getErrorCorrectMapping`. Barcodes with several candidates are not assigned.

## Current scope

This batch covers cutadapt adapter alignment, FASTQ adapter trimming, quality-trim intervals and expected error counts, umi-tools UMI clustering, regex barcode extraction, and whitelist correction, and pyslow5 SLOW5/BLOW5 writing, summary statistics, and single-read reading.

The following are not included in this batch:

- **Other cutadapt features:** poly-A trimming, paired-end trimming, and command-line calls are not wrapped. The existing `run_cutadapt` in `dnakit.sequencing_qc` is a command-line adapter and does not replace the Python API functions in this batch.

**Crash risk in pyslow5:** With pyslow5 1.5.0, reading a corrupt SLOW5/BLOW5 file can make the Python interpreter exit with a segmentation fault. The wrapper checks the suffix and the header magic first, and rejects empty files, text files, and files with the wrong suffix. A file whose magic is correct can still crash the interpreter if its header or contents are corrupt. In testing, a corrupt header line after a valid magic line caused a crash. A corrupt record can also be skipped silently, which makes the statistics too small. Open only SLOW5/BLOW5 files from trusted sources.

pyslow5's random-access functions (looking up a `read_id` directly) create a `.slow5.idx` index file next to the input. This wrapper uses sequential scans only, so it does not create that file.

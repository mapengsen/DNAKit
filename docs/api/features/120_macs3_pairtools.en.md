# MACS3 and pairtools: peak calling and Hi-C pair processing

This group of functions in `dnakit.epigenome` is a set of command-line facades over two packages: [MACS3](https://github.com/macs3-project/MACS) (peak calling, signal tracks, fragment-size models, variant calling in peaks and HMMRATAC accessibility calling) and [pairtools](https://github.com/open2c/pairtools) (parsing, sorting, deduplicating, filtering, phasing and summarising Hi-C pairs). Each function runs one fixed subcommand with an explicit argument list (no shell), refuses to overwrite an existing output, and returns a dictionary with `status`, `backend`, `version`, `command`, `return_code`, `outputs` and `log_tail`. The `status` is `completed` only when the program exits with code 0 and every expected output file exists. They do not download data or call a remote service.

According to the package metadata, MACS3 3.0.5 is BSD-3-Clause and pairtools 1.1.2 is MIT licensed. DNAKit starts them as separate programs and copies none of their code; only `pairtools_mark_split_pair_as_dup()` imports a pairtools module.

The dependencies are optional (extras `dnakit[bio-macs3]` and `dnakit[bio-pairtools]`) and are used only when a function is called. If a program is missing, the function raises `BackendUnavailableError` with an install hint. The examples import from `dnakit.epigenome` and call every function with `verbose=False`; they find the programs next to the Python interpreter, so they also work in a virtual environment that is not on PATH.

## 1) `dnakit.epigenome.call_atac_peaks_hmmratac()`

- **Purpose:** Call accessible regions of an ATAC-seq experiment from paired-end fragments with the HMMRATAC hidden Markov model.
- **Method:** Check the arguments, then run `macs3 hmmratac` with `-i`, `-f`, `-n`, `--outdir`, `-l`, `-u`, `-c`, `--minlen`, `--maxTrain`, `--randomSeed` and `--hmm-type` (plus `-t` for `training_regions` and `--save-states`). `output_dir` is created by the function and must not exist yet. The status is `completed` only when `<name>_accessible_regions.narrowPeak`, `<name>_cutoff_analysis.tsv` and `<name>_model.json` (and `<name>_states.bed` with `save_states`) all exist. When MACS3 finds no training region it stops with "Not enough training regions" and the status is `failed`.
- **API:** `call_atac_peaks_hmmratac(ifile: 'Sequence[str]', output_dir: 'str', *, name: 'str' = 'NA', file_format: 'str' = 'BAMPE', lower_cutoff: 'int' = 10, upper_cutoff: 'int' = 20, prescan_cutoff: 'float' = 1.2, min_region: 'int' = 100, max_training: 'int' = 1000, random_seed: 'int' = 10151, hmm_type: 'str' = 'gaussian', training_regions: 'str | None' = None, save_states: 'bool' = False, macs3_path: 'str | None' = None, verbose: bool = True) -> 'dict[str, Any]'`.
- **Requirements:** Needs the optional package MACS3 (extra `dnakit[bio-macs3]`), which installs the `macs3` program. DNAKit looks for the program at `macs3_path`, then on PATH, then next to the running Python interpreter; if it is missing, `BackendUnavailableError` is raised before the program is started.
- **Input:** `ifile` is a list of existing fragment files; `file_format` is `BAMPE` (default), `BEDPE` or `FRAG`. `lower_cutoff` must be smaller than `upper_cutoff` (fold-change bounds for choosing training regions, default 10 and 20). `prescan_cutoff` (default 1.2), `min_region` (default 100), `max_training` (default 1000) and `random_seed` (default 10151) are passed on; `hmm_type` is `gaussian` (default) or `poisson`. `training_regions` is an optional existing BED file. `name` may contain only letters, digits, `_`, `.` and `-`.
- **Output:** The common result dictionary plus `output_dir` and `accessible_regions` (the path of the narrowPeak file, or `None` if it was not written).
- **Example code:**

```python
import random
import tempfile
from pathlib import Path

from dnakit.epigenome import call_atac_peaks_hmmratac

work = Path(tempfile.mkdtemp())
rng = random.Random(0)
rows = []
for centre in (2000, 6000, 10000):
    for _ in range(40):
        start = centre + rng.randint(-100, 100)
        rows.append(f"chr1\t{start}\t{start + rng.randint(50, 150)}")
for _ in range(40):
    start = rng.randint(0, 15000)
    rows.append(f"chr1\t{start}\t{start + rng.randint(100, 300)}")
fragments = work / "fragments.bedpe"
fragments.write_text("\n".join(rows) + "\n")

result = call_atac_peaks_hmmratac(
    [str(fragments)], str(work / "out"), name="demo",
    file_format="BEDPE", save_states=True, verbose=False,
)
print(result["status"], result["return_code"])
print(sorted(Path(p).name for p in result["outputs"]))
states = (work / "out" / "demo_states.bed").read_text().splitlines()
print(len(states), sorted({line.split("\t")[3] for line in states}))
print(result["accessible_regions"] is not None)
```

- **Example output:**

```text
completed 0
['demo_accessible_regions.narrowPeak', 'demo_cutoff_analysis.tsv', 'demo_model.json', 'demo_states.bed']
19 ['nuc', 'open']
True
```

## 2) `dnakit.epigenome.call_broad_peaks_from_bedgraph()`

- **Purpose:** Call nested broad peaks from a score bedGraph and write them as a gappedPeak table.
- **Method:** Run `macs3 bdgbroadcall` with `-i`, `-c` (`cutoff_peak`), `-C` (`cutoff_link`), `-l`, `-g` (`lvl1_max_gap`), `-G` (`lvl2_max_gap`) and `-o`; `--no-trackline` is added when `trackline` is false. Regions at or above `cutoff_peak` become the broad regions, and the nearby cores above `cutoff_link` inside them are linked as blocks.
- **API:** `call_broad_peaks_from_bedgraph(bedgraph: 'str', output_file: 'str', *, cutoff_peak: 'float' = 2.0, cutoff_link: 'float' = 1.0, min_length: 'int' = 200, lvl1_max_gap: 'int' = 30, lvl2_max_gap: 'int' = 800, trackline: 'bool' = True, macs3_path: 'str | None' = None, verbose: bool = True) -> 'dict[str, Any]'`.
- **Requirements:** Needs the optional package MACS3 (extra `dnakit[bio-macs3]`), which installs the `macs3` program. DNAKit looks for the program at `macs3_path`, then on PATH, then next to the running Python interpreter; if it is missing, `BackendUnavailableError` is raised before the program is started.
- **Input:** `bedgraph` is an existing score bedGraph and `output_file` a new path in an existing folder. `cutoff_peak` (default 2.0), `cutoff_link` (default 1.0), `min_length` (default 200, at least 1), `lvl1_max_gap` (default 30) and `lvl2_max_gap` (default 800) are numbers; `trackline` (default true) writes the UCSC track line.
- **Output:** The common result dictionary. The output file has 15 columns (BED12 plus three score columns); the region name contains the output path.
- **Example code:**

```python
import tempfile
from pathlib import Path

from dnakit.epigenome import call_broad_peaks_from_bedgraph

out = Path(tempfile.mkdtemp()) / "broad.bed"
result = call_broad_peaks_from_bedgraph(
    "treat.bdg", str(out), cutoff_peak=10, cutoff_link=1, min_length=100,
    lvl1_max_gap=50, lvl2_max_gap=300, trackline=False, verbose=False,
)
print(result["status"], result["return_code"])
for line in out.read_text().splitlines():
    fields = line.split("\t")
    print(len(fields), fields[0], fields[1], fields[2], fields[4], fields[9], fields[10], fields[11])
```

- **Example output:**

```text
completed 0
15 chr1 0 1000 150 4 1,300,300,1 0,100,600,999
```

## 3) `dnakit.epigenome.call_chip_peaks()`

- **Purpose:** Call peaks from ChIP-seq or ATAC-seq alignments.
- **Method:** Check every option, then run `macs3 callpeak` in a new `output_dir` with `-t`, optional `-c`, `-f`, `-g`, `--keep-dup`, `-n`, `--outdir`, the model options (`--shift`, `--extsize`, `--bw`, `--d-min`, `-m`, `--nomodel`, `--fix-bimodal`) and the cutoff options (`-q` or `-p`, `--slocal`, `--llocal`, `--fe-cutoff`, `--broad`, `--call-summits`). The status is `completed` only if the exit code is 0 and the expected files exist: `<name>_peaks.narrowPeak` (or `.broadPeak` plus `.gappedPeak` with `broad`), `<name>_peaks.xls`, and the files that follow the options (summits, bedGraph tracks, cutoff analysis). Unless `nomodel` is set, MACS3 builds a fragment-size model and needs enough paired plus/minus strand peaks; if it cannot, the subcommand fails and the status is `failed`.
- **API:** `call_chip_peaks(treatment: 'Sequence[str]', output_dir: 'str', *, control: 'Sequence[str] | None' = None, name: 'str' = 'NA', file_format: 'str' = 'AUTO', genome_size: 'str | float' = 'hs', tag_size: 'int | None' = None, keep_duplicates: 'str | int' = '1', max_count: 'int | None' = None, barcodes: 'str | None' = None, save_bedgraph: 'bool' = False, spmr: 'bool' = False, trackline: 'bool' = False, nomodel: 'bool' = False, shift: 'int' = 0, extsize: 'int' = 200, bandwidth: 'int' = 300, min_fragment: 'int' = 20, mfold: 'Sequence[int]' = (5, 50), fix_bimodal: 'bool' = False, qvalue: 'float | None' = 0.05, pvalue: 'float | None' = None, scale_to: 'str | None' = None, down_sample: 'bool' = False, seed: 'int | None' = None, nolambda: 'bool' = False, small_local: 'int' = 1000, large_local: 'int' = 10000, max_gap: 'int | None' = None, min_length: 'int | None' = None, broad: 'bool' = False, broad_cutoff: 'float' = 0.1, cutoff_analysis: 'bool' = False, call_summits: 'bool' = False, fe_cutoff: 'float' = 1.0, macs3_path: 'str | None' = None, verbose: bool = True) -> 'dict[str, Any]'`.
- **Requirements:** Needs the optional package MACS3 (extra `dnakit[bio-macs3]`), which installs the `macs3` program. DNAKit looks for the program at `macs3_path`, then on PATH, then next to the running Python interpreter; if it is missing, `BackendUnavailableError` is raised before the program is started.
- **Input:** `treatment` is a list of existing alignment files and `control` an optional list; `file_format` is `AUTO` (default), `BAM`, `SAM`, `BED`, `ELAND`, `ELANDMULTI`, `ELANDEXPORT`, `BOWTIE`, `BAMPE`, `BEDPE` or `FRAG`. `genome_size` is `hs`, `mm`, `ce`, `dm` or a positive number of bp. `qvalue` (default 0.05) and `pvalue` are mutually exclusive: pass `qvalue=None` to use `pvalue`. `mfold` is `(lower, upper)` with lower below upper. `scale_to` is `large` or `small`. `output_dir` must not exist; `name` may contain only letters, digits, `_`, `.` and `-`. The other options (`tag_size`, `keep_duplicates`, `max_count`, `barcodes`, `save_bedgraph`, `spmr`, `trackline`, `nomodel`, `shift`, `extsize`, `bandwidth`, `min_fragment`, `fix_bimodal`, `down_sample`, `seed`, `nolambda`, `small_local`, `large_local`, `max_gap`, `min_length`, `broad`, `broad_cutoff`, `cutoff_analysis`, `call_summits`, `fe_cutoff`) map to the matching `callpeak` flags.
- **Output:** The common result dictionary plus `output_dir`, `peak_files` (the peak files that exist), `xls_file` (path or `None`) and `model_script` (the `<name>_model.r` path, or `None`; always `None` with `nomodel`).
- **Example code:**

```python
import tempfile
from pathlib import Path

from dnakit.epigenome import call_chip_peaks

out = Path(tempfile.mkdtemp()) / "peaks"
result = call_chip_peaks(
    ["reads.bed"], str(out), name="demo", file_format="BED", genome_size=5000,
    nomodel=True, extsize=100, qvalue=0.5, verbose=False,
)
print(result["status"], result["return_code"])
print(sorted(Path(p).name for p in result["outputs"]))
print([Path(p).name for p in result["peak_files"]], result["model_script"])
for line in Path(result["peak_files"][0]).read_text().splitlines():
    print(line)
```

## 4) `dnakit.epigenome.call_peaks_from_bedgraph()`

- **Purpose:** Call narrow peaks from a score bedGraph such as a bdgcmp track.
- **Method:** Run `macs3 bdgpeakcall` with `-i`, `-c`, `-l`, `-g` and `-o` (plus `--call-summits` and `--no-trackline` when requested). Regions whose score is at least `cutoff` are merged across gaps up to `max_gap` and kept when they are at least `min_length` bp long.
- **API:** `call_peaks_from_bedgraph(bedgraph: 'str', output_file: 'str', *, cutoff: 'float' = 5.0, min_length: 'int' = 200, max_gap: 'int' = 30, call_summits: 'bool' = False, trackline: 'bool' = True, macs3_path: 'str | None' = None, verbose: bool = True) -> 'dict[str, Any]'`.
- **Requirements:** Needs the optional package MACS3 (extra `dnakit[bio-macs3]`), which installs the `macs3` program. DNAKit looks for the program at `macs3_path`, then on PATH, then next to the running Python interpreter; if it is missing, `BackendUnavailableError` is raised before the program is started.
- **Input:** `bedgraph` is an existing score bedGraph and `output_file` a new path in an existing folder. `cutoff` (default 5.0), `min_length` (default 200, at least 1) and `max_gap` (default 30, at least 0) are numbers; `call_summits` (default false) splits peaks at summits; `trackline` (default true) writes the UCSC track line.
- **Output:** The common result dictionary. The output is a narrowPeak-style table; the peak name contains the output path.
- **Example code:**

```python
import tempfile
from pathlib import Path

from dnakit.epigenome import call_peaks_from_bedgraph

out = Path(tempfile.mkdtemp()) / "peaks.bed"
result = call_peaks_from_bedgraph(
    "treat.bdg", str(out), cutoff=5, min_length=100, max_gap=50,
    trackline=False, verbose=False,
)
print(result["status"], result["return_code"])
for line in out.read_text().splitlines():
    fields = line.split("\t")
    print(fields[0], fields[1], fields[2], fields[4])
```

- **Example output:**

```text
completed 0
chr1 100 400 120
chr1 600 900 150
```

## 5) `dnakit.epigenome.call_variants_in_peaks()`

- **Purpose:** Call SNVs and small indels inside peak regions from a BAM file and write a VCF.
- **Method:** Run `macs3 callvar` with `-b`, `-t`, optional `-c`, `-o`, `-Q`, `-D`, `-g`, `-G`, `-F`, `--fermi-overlap`, `--top2alleles-mratio`, `--altallele-count`, `--max-ar` and `-m`. After the run it counts the lines "No reads found in this peak" in the log tail and lists them in `warnings`, because MACS3 reports such peaks as skipped and still exits with code 0.
- **API:** `call_variants_in_peaks(peaks_bed: 'str', treatment_bam: 'str', output_vcf: 'str', *, control_bam: 'str | None' = None, min_base_quality: 'int' = 20, max_duplicates: 'int' = 1, gq_hetero: 'int' = 0, gq_homo: 'int' = 0, fermi: 'str' = 'auto', fermi_min_overlap: 'int' = 30, top2alleles_min_ratio: 'float' = 0.8, altallele_min_count: 'int' = 2, max_allowed_ar: 'float' = 0.95, processes: 'int' = 1, macs3_path: 'str | None' = None, verbose: bool = True) -> 'dict[str, Any]'`.
- **Requirements:** Needs the optional package MACS3 (extra `dnakit[bio-macs3]`), which installs the `macs3` program. DNAKit looks for the program at `macs3_path`, then on PATH, then next to the running Python interpreter; if it is missing, `BackendUnavailableError` is raised before the program is started. The example also needs pysam (extra `dnakit[bio-reads]`) to write a small BAM file.
- **Input:** `peaks_bed` is an existing BED file with at least four columns; `treatment_bam` (and optional `control_bam`) must be sorted, indexed and carry MD tags (for example from `samtools calmd`); `output_vcf` is a new path. `min_base_quality` (default 20), `max_duplicates` (default 1), `gq_hetero`, `gq_homo` (default 0), `fermi` (`auto`, `on` or `off`), `fermi_min_overlap` (default 30), `top2alleles_min_ratio` and `max_allowed_ar` (between 0 and 1), `altallele_min_count` (default 2) and `processes` (default 1) are checked and passed on.
- **Output:** The common result dictionary plus `warnings` (a list of strings, empty when no peak was skipped).
- **Example code:**

```python
import tempfile
from pathlib import Path

import pysam

from dnakit.epigenome import call_variants_in_peaks

work = Path(tempfile.mkdtemp())
reference = "ACGT" * 250
header = {"HD": {"VN": "1.6", "SO": "coordinate"}, "SQ": [{"SN": "chr1", "LN": 1000}]}
bam = str(work / "reads.bam")
with pysam.AlignmentFile(bam, "wb", header=header) as handle:
    for i in range(10):
        start = 90 + i
        bases = list(reference[start:start + 40])
        md = "40"
        if i < 6:
            offset = 120 - start
            bases[offset] = "T"
            md = f"{offset}{reference[120]}{40 - offset - 1}"
        read = pysam.AlignedSegment()
        read.query_name = f"read{i}"
        read.query_sequence = "".join(bases)
        read.flag = 0
        read.reference_id = 0
        read.reference_start = start
        read.mapping_quality = 60
        read.cigar = [(0, 40)]
        read.query_qualities = pysam.qualitystring_to_array("I" * 40)
        read.set_tag("MD", md)
        handle.write(read)
pysam.index(bam)
(work / "peaks.bed").write_text("chr1\t80\t160\tpeak1\n")

out = work / "variants.vcf"
result = call_variants_in_peaks(str(work / "peaks.bed"), bam, str(out), verbose=False)
print(result["status"], result["warnings"])
for line in out.read_text().splitlines():
    if not line.startswith("#"):
        fields = line.split("\t")
        info = dict(item.split("=") for item in fields[7].split(";"))
        print(fields[0], fields[1], fields[3], fields[4], info["MT"], info["DPT"], fields[9])
```

## 6) `dnakit.epigenome.combine_replicate_bedgraphs()`

- **Purpose:** Combine the score tracks of two or more replicates into one bedGraph.
- **Method:** Run `macs3 cmbreps` with `-i`, `-m` and `-o`. `fisher` combines -log10 p-values with Fisher's method, `max` and `mean` take the maximum or the average of the scores as they are.

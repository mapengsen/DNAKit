# Third-party MCP tool catalogue

DNAKit read the tool lists of 49 third-party MCP servers and kept **1,402** DNA and gene tools (built 2026-10-16). Each server has a page listing every kept tool with its summary, arguments and the call through DNAKit. The search and call functions are described in the [MCP tool index](../../api/features/111_mcp_tool_index.md); the [web demo](https://dnakit.mapengsen.asia/) searches the same tools in its MCP tools tab.

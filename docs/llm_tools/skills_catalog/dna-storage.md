## `dnakit-dna-storage` {#dnakit-dna-storage}

Encode bytes into DNA payloads and decode intact packets through the optional Chamaeleo Goldman codec. Use for computational DNA storage demonstrations and codec integration.

- **来源：**[DNAKit contributors; method authors cited in SKILL.md and DNAKIT.md @ `dnakit-`](https://github.com/mapengsen/DNAKit/tree/main/skills/dnakit-dna-storage)
- **许可证：**`MIT`
- **运行依赖：**Python 模块 `dnakit`, `Chamaeleo`
- **核对：**元数据 通过，资源 已校验，执行 未运行

```bash
dnakit skills info dnakit-dna-storage
dnakit skills install dnakit-dna-storage --agent claude-code   # 或 --agent codex / cursor
```
